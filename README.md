# SAORI TANIZAWA — Portfolio

静的Webポートフォリオです。HTML・CSS・JavaScript・作品データを分けて管理しています。

## ファイル構成

- `index.html`：ページの構造
- `css/style.css`：デザイン・レスポンシブ設定
- `js/main.js`：表示、カテゴリー切り替え、モーダル、追加プレビューの処理
- `js/projects.js`：作品データ
- `images/`：作品画像を格納するフォルダ（必要に応じて作成）

## カテゴリー

チラシ・販促物／パンフレット／ロゴ／SNS・広告／求人広告／WEBサイト／エディトリアル／その他

## 作品の編集

`js/projects.js` の `projects` 配列に作品情報を登録してください。画像は `images/` に配置し、作品データの `image` に相対パス（例：`images/work01.jpg`）を指定します。

## 作品追加フォームについて

ページ上部の「作品を追加」はブラウザ上で一時的にプレビューするための機能です。追加した作品は再読み込みすると消えます。公開サイトに恒久的に追加する場合は、画像ファイルを配置し、`js/projects.js` の作品データを更新して再デプロイしてください。

## 公開

このフォルダ内のファイル一式を、GitHub Pages・Netlify・Cloudflare Pagesなどの静的ホスティングにアップロードしてください。`index.html` だけでなく、`css/` と `js/` も同じ階層のまま公開する必要があります。

## 公開前チェック

- `your-email@example.com` を公開用メールアドレスに置き換える
- サンプルの作品名・説明・担当範囲を実績に合わせて更新する
- 公開許可のない制作物、顧客名、個人情報、未公開情報が含まれていないか確認する
- PC・スマートフォンで表示と操作を確認する

※今回の提供データには作品画像ファイルが含まれていないため、サンプル作品はプレースホルダー表示です。
